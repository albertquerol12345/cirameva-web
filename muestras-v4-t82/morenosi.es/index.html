Cómo utilizar el archivo

  1. Sustituye partidas, unidades, acumulados y precios por las mediciones de la obra. Las filas vacías permiten añadir siete partidas.
  2. La cantidad mensual es acumulado actual menos anterior; el importe es esa diferencia multiplicada por el precio unitario. Si hay una corrección negativa, revísala antes de aceptar.
  3. Revisa el total de las diez líneas. Este ejemplo no aplica impuestos, retenciones ni anticipos.
  4. La dirección facultativa revisa las mediciones y expide la certificación; esta hoja organiza la relación valorada.
